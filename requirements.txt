# =============================================================================
# BotTrade — AI Trading Bot with RAG Architecture
# requirements.txt — runtime dependencies, Python 3.11+
#
# Every version here is pinned to the stack the test suite actually runs on.
# The Dockerfile builds from this file, so a drift between these pins and the
# developed-against versions means production runs code that was never tested.
# If you upgrade something, run `pytest` and update the pin in the same commit.
#
# Development-only tools (pytest, ruff, mypy, black) live in requirements-dev.txt.
# vectorbt lives in requirements-backtesting.txt - see the note there.
